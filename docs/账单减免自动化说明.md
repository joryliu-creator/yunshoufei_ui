# 账单减免自动化专项

账单减免流程以 `docs/账单减免流程.md` 为业务来源。原流程第 1 步的房间号写成 1106，但后续筛选、方案和金额断言均为 1101；专项用例按后续一致值使用 1101。

## 自动化资产

- Page Object：`src/pages/bill_discount_page.py`
- pytest 用例：`tests/billing/test_bill_discount.py`
- Excel 数据：`UI自动化回归测试用例模板_Demo.xlsx` 的“账单减免专项”与“收费场景配置”
- 场景编号：`YSF-SCENE-DISCOUNT-1101`
- 用例编号：`YSF-BILL-DISCOUNT-1101`

## 安全开关

真实操作默认关闭。仅在标准一测试环境、确认 1101 账单和长期减免方案均可操作时开启：

```powershell
$env:ALLOW_BILL_DISCOUNT='true'
$env:ALLOW_BILL_CREATION='true'
$env:CLEANUP_CREATED_BILL='true'
$env:ALLOW_BILL_DELETION='true'
```

长期业务方案“减免方案-按折扣”只被选择，不由专项用例删除。账单验证完成后，按账期 + 房间 + 收费项在账单中心作废、确认作废、删除，并复查结果为 0。

## 执行

```powershell
.\.venv\Scripts\python.exe -m pytest tests/billing/test_bill_discount.py `
  --test-env standard1 --customer-id 93537 `
  --html=artifacts/bill-discount.html --self-contained-html -q
```

未开启 `ALLOW_BILL_DISCOUNT` 时，pytest 只收集专项用例并安全跳过，不会创建账单、发起审核或删除数据。
