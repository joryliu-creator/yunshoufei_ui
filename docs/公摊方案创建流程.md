## 一、周期公摊方案创建流程

截图如下：![57271f89-6846-44bf-a4bd-e38e7acd00e7](file:///C:/Users/Administrator/Pictures/Typedown/57271f89-6846-44bf-a4bd-e38e7acd00e7.png)

操作流程：

1、顶部导航栏点击云收费

2、进入左侧收费设置-公摊方案下

3、点击右上角新增方案按钮

4、等待右侧弹出新增公摊方案抽屉

5、在“请输入方案名称”输入框内输入“UI周期类+对应的公摊方式”

6、点击“请选择收费项类型”下拉框，正常展示列表数据后，选择“周期性费用”

7、等待上一步成功后，点击“请选择收费项”下拉框，正常展示列表数据后，选择“公摊周期性收费项”

8、等待上一步成功后，点击“请选择收费标准”下拉框，正常展示列表数据后，选择“UI公摊周期性收费标准”

9、点击“请选择公摊方式”下拉框，展示三种公摊方式：按房间设置比例分摊、按房间设置金额分摊、按住户面积及所在楼层对应系数公摊

10、一、选择“按房间设置比例分摊”时：

1. 先清空公摊金额右侧的输入框，输入1000

2. 点击公摊房间右侧的选择房间组件，勾选对应的两个房间后，点击组件底部的确定按钮

3. 在房间列表的第一行，分摊比例那一列，将清空输入框，填充40

4. 在房间列表的第二行，分摊比例那一列，将清空输入框，填充60

5. 点击右下角保存按钮，保存成功后进入方案列表页，提示保存成功。

![367b24a1-6c9b-469d-8be9-255738e6aaaa](file:///C:/Users/Administrator/Pictures/Typedown/367b24a1-6c9b-469d-8be9-255738e6aaaa.png)

二、选择“按房间设置金额分摊”时：

1. 先清空公摊金额右侧的输入框，输入1000

2. 点击公摊房间右侧的选择房间组件，勾选对应的两个房间后，点击组件底部的确定按钮

3. 在房间列表的第一行，分摊金额那一列，将清空输入框，填充300

4. 在房间列表的第二行，分摊金额那一列，将清空输入框，填充700

5. 点击右下角保存按钮，保存成功后进入方案列表页，提示保存成功。

![fed7bdf8-e761-4a68-8c6d-4657270d4755](file:///C:/Users/Administrator/Pictures/Typedown/fed7bdf8-e761-4a68-8c6d-4657270d4755.png)

二、选择“按住户面积及所在楼层对应系数公摊”时：

1、计费面积选择对应的计费面积：建筑面积、使用面积、收费面积

2、点击公摊房间右侧的选择房间组件，勾选对应的两个房间后，点击组件底部的确定按钮

3、在“请输入标准面积单价”输入框内输入2

4、在设置阶梯价格区域，低于/等于右侧第一个输入框填写5，第二个输入框系数填写3

5、阶梯列表第二行，高于/等于右侧第一个输入框不需要填写，第二个输入框填写5

6、点击右侧保存按钮，进入方案列表页提示保存成功

## 二、仪表公摊方案创建流程

![image-20260923120059644](D:\lz\autotest\docs\图片\仪表公摊方案.png)

操作流程：

1、顶部导航栏点击云收费

2、进入左侧收费设置-公摊方案下

3、点击右上角新增方案按钮

4、等待右侧弹出新增公摊方案抽屉

5、在“请输入方案名称”输入框内输入“UI仪表类+对应的公摊方式”

6、点击“请选择收费项类型”下拉框，正常展示列表数据后，选择“仪表类费用”

7、点击“请选择仪表类型”下拉框，如果是水表类型则选择水表、电表类型则选择电表

8、等待上一步页面成功加载后，点击“请选择收费项”下拉框，正常展示列表数据后，选择“UI公摊水费”；如果7步骤选择的是电表，则选择“UI公摊电费”；

9、等待上一步成功后，点击“请选择收费标准”下拉框，正常展示列表数据后，选择“公摊水费收费标准”；如果第8步骤内选择的是“UI公摊电费”，则收费标准选择为“公摊电费收费标准”；

10、点击“请选择公摊方式”下拉框，展示四种公摊方式：按户分摊、按计费面积分摊、按住户所在楼层对应系数分摊、按住户计费面积对应系数分摊

11、一、按户分摊时：

![image-20260923135717085](D:\lz\autotest\docs\图片\仪表类按户分摊.png)

1. 公摊方式选择好后，等待页面元素加载成功，公摊户数/面积右侧输入框，会自动填充2
2. 不足月公摊规则有按满月计费或者按天计费
3. 公摊房间列表展示对应的仪表关联的房间
4. 点击右侧保存按钮，进入方案列表页提示保存成功

二、按计费面积分摊时：

![image-20260923140244580](D:\lz\autotest\docs\图片\计费面积分摊.png)

1. 公摊方式选择好后，等待页面元素加载成功，计费面积有三个选择：建筑面积、使用面积、收费面积
2. 公摊户数/面积右侧的输入框自动填充为仪表关联房间的两个面积总和
3. 不足月公摊规则有按满月计费或者按天计费
4. 公摊房间列表展示对应的仪表关联的房间
5. 点击右侧保存按钮，进入方案列表页提示保存成功

三、按住户所在楼层对应系数分摊时：

![image-20260923141135079](D:\lz\autotest\docs\图片\按住户所在楼层对应系数分摊.png)

1. 公摊方式选择好后，等待页面元素加载成功
2. 不足月公摊规则有按满月计费或者按天计费
3. 公摊房间列表展示对应的仪表关联的房间
4. 设置阶梯价格区域：第一行左侧低于/等于右侧输入框填写2、户数一列的输入框填写4、系数一列填写为3；第二行，楼层一列输入框自动会填充为3，户数一列的输入框填写4、系数一列填写为5；
5. 点击右侧保存按钮，进入方案列表页提示保存成功

四、按住户所在楼层对应系数分摊时：

1. 公摊方式选择好后，等待页面元素加载成功，计费面积有三个选择：建筑面积、使用面积、收费面积
2. 公摊户数/面积右侧的输入框自动填充为仪表关联房间的两个面积总和
3. 不足月公摊规则有按满月计费或者按天计费
4. 公摊房间列表展示对应的仪表关联的房间
5. 在设置阶梯价格区域，第一行低于/等于右侧第一个输入框填写5，第二个输入框系数填写3
6. 阶梯列表第二行，高于/等于右侧第一个输入框不需要填写，第二个输入框填写5
7. 点击右侧保存按钮，进入方案列表页提示保存成功
