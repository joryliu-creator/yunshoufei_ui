# 发版前全量回归补充

发版前执行全部出账场景及全部专项测试场景，保持一次登录、串行执行，并在模块切换前完成清理。

```powershell
.\.venv\Scripts\python.exe scripts\run_jenkins_regression.py `
  --test-env standard1 --customer-id 93537 --account-role default --max-minutes 0
```

收费标准专项需开启以下开关，仅清理本次运行创建且带 `AT-` 前缀的收费标准：

```powershell
$env:ALLOW_CHARGE_STANDARD_CREATION="true"
$env:CLEANUP_CREATED_CHARGE_STANDARDS="true"
$env:ALLOW_CHARGE_STANDARD_DELETION="true"
.\.venv\Scripts\python.exe -m pytest tests\billing\test_charge_standard_lifecycle.py
```

执行顺序固定为：账单中心 → 清理并确认无残留 → 计费出账 → 清理相关账单 → 临时台账 → 清理临时台账记录。账单中心和计费出账账单使用账期+房间+收费项定位，临时台账账单只在临时台账列表清理。

报告统一查看 `artifacts/`；失败时查看 `live-results.jsonl`、`browser-errors.jsonl` 和 `test-results/`。
