# 减免方案

### 新增减免方案

1、顶部导航栏点击云收费页签

2、点击左侧收费设置->减免方案-新页签，左上角项目选择云收费UI自动化项目

3、点击右上角新增按钮

4、在减免方案名称右侧的输入框内输入名称：可以采用减免规则+方案命名

5、减免规则可以选择共6种

- 减免规则选择按折扣时，下一行左侧字段名称显示为减免折扣，在右侧输入框输入5
- 减免规则选择按固定金额时，下一行左侧字段名称显示为固定金额，在右侧输入框输入5
- 选择自定义金额时，下一行左侧字段名称包含超额审批
- 选择违约金全免时，下一行左侧字段名称包含超额审批
- 选择违约金折扣时，下一行左侧字段名称显示违约金折扣，右侧输入框内输入5
- 选择抹零减免时，下一行左侧字段名称包含超额审批

6、下一行 超额审批，右侧输入框输入1

7、备注一行，输入框输入autotest

8、点击确定按钮，完成减免方案的创建

9、回到列表页面提示，新增成功

### 删除减免方案

1、顶部导航栏点击云收费页签

2、点击左侧收费设置->减免方案-新页签，左上角项目选择云收费UI自动化项目

3、在项目右侧减免方案名称右侧输入框输入方案的名称后，再点击右侧的搜索按钮

4、点击列表数据中的最右侧的删除按钮，弹出提示弹窗

5、点击弹窗内的确定按钮，确定删除，提示删除成功

6、再次通过方案名称搜索，列表内无数据

### 自动化执行

自动化实现：

- Page Object：`src/pages/discount_scheme_page.py`
- pytest 用例：`tests/billing/test_discount_schemes.py`
- 覆盖房间及规则：1101 按折扣、1102 按固定金额、1103 自定义金额、1104 违约金全免、1105 违约金折扣、1106 抹零减免。

减免方案名称使用 `AT-<减免规则>-<房间号>`，在保留业务可追溯性的同时避免超过页面名称长度限制。

三个安全开关默认均关闭：

- `ALLOW_DISCOUNT_SCHEME_CREATION=true`：允许真实创建减免方案。
- `CLEANUP_DISCOUNT_SCHEMES=true`：创建完成后执行清理。
- `ALLOW_DISCOUNT_SCHEME_DELETION=true`：允许永久删除；只有它与清理开关同时开启才执行删除。

标准一真实创建并清理六种方案：

```powershell
$env:ALLOW_DISCOUNT_SCHEME_CREATION='true'
$env:CLEANUP_DISCOUNT_SCHEMES='true'
$env:ALLOW_DISCOUNT_SCHEME_DELETION='true'
.\.venv\Scripts\python.exe -m pytest tests/billing/test_discount_schemes.py --test-env standard1 --customer-id 93537 --html=artifacts/discount-schemes.html --self-contained-html -q
```

已验证规则：创建前按名称清理上次中断遗留的同名自动化方案；创建后按名称精确回查；删除操作需映射 Element UI 固定右侧操作列；删除后重复同名查询并要求结果为 0。

### 长期减免方案与自动化临时方案

用于账单减免的长期方案使用以下名称并保留，不纳入自动化清理：

- 减免方案-按折扣
- 减免方案-按固定金额
- 减免方案-自定义金额
- 减免方案-违约金全免
- 减免方案-违约金折扣
- 减免方案-抹零减免

自动化脚本默认使用 `AT-<减免规则>-<房间号>`，并在创建后执行清理。创建长期方案时需要显式设置：

```powershell
$env:DISCOUNT_SCHEME_PREFIX='减免方案'
$env:DISCOUNT_SCHEME_INCLUDE_ROOM='false'
$env:ALLOW_DISCOUNT_SCHEME_CREATION='true'
$env:CLEANUP_DISCOUNT_SCHEMES='false'
$env:ALLOW_DISCOUNT_SCHEME_DELETION='false'
```
